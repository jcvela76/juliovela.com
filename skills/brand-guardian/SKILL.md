# brand-guardian

## Skill purpose
Protect and enforce `:// JULIO VELA` brand identity and tone.

## When to use it
Use before drafting, reviewing, or approving any public-facing copy or visuals.

## Inputs it expects
- Draft copy, headlines, visual brief, or prompt
- Channel context (website, LinkedIn, article)

## Output it should produce
- Brand-aligned content recommendations
- Approved/revision decision and rationale
- A compact checklist of enforcement outcomes

## Guardrails
- Logo must be `:// JULIO VELA`.
- Subtitle must be `TECH SOLUTIONS`.
- Palette must include: `#E11D2E`, `#1F2329`, `#2B2F36`, `#9AA0A6`, `#F5F6F7`, `#FFFFFF`.
- Tone: practical, technical, clear, modern.
- Avoid generic AI hype, robots, circuits, neon cyberpunk, clutter.

## Checklist
- [ ] Identity text appears correctly where brand context is needed
- [ ] Palette references are respected
- [ ] No over-hyped wording
- [ ] Visual direction is minimal and clean
- [ ] Message remains practical and useful

## Example prompt
"Review this draft and apply Julio Vela brand constraints: identity, palette, and tone, removing hype and clutter."
