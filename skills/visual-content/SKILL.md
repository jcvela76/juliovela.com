# visual-content

## Skill purpose
Define image directions and prompts for blog covers and social graphics.

## When to use it
Use for creating visual guidance before finalizing cover images or social assets.

## Inputs it expects
- Content topic and desired message
- Medium (blog cover, LinkedIn post, future carousel)
- Brand constraints

## Output it should produce
- Concrete image prompt
- Visual concept and style
- Alt text
- Image approval checklist

## Guardrails
- Palette must follow brand colors: `#E11D2E`, `#1F2329`, `#2B2F36`, `#9AA0A6`, `#F5F6F7`, `#FFFFFF`.
- Keep minimal style and practical composition.
- No generic AI robot visuals.
- No stolen/imitated styles.
- No fake screenshots.
- Always include alt text.

## Checklist
- [ ] Prompt references required palette
- [ ] Style is minimal and clear
- [ ] No disallowed visual tropes
- [ ] Alt text included
- [ ] Approval checklist completed

## Example prompt
"Generate a minimal, practical cover prompt and alt text for this technical article using only approved brand colors."
