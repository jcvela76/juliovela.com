# Project Overview

`juliovela.com` is the foundation for the Julio Vela personal technology brand.

## Purpose
- Centralize practical technology content (AI tools, automation, software strategy, and web/software solutions).
- Share readable technical guidance and reusable assets for LinkedIn.
- Deliver content through a documented, approval-first workflow.

## Brand
- Logo: `:// JULIO VELA`
- Subtitle: `TECH SOLUTIONS`
- Personality: practical, technical, clear, modern, minimal, trustworthy.

## Scope of this repo
This slice defines instructions, governance, and documentation structure. No production code is scaffolded yet.

## Core operating principles
- Documentation first
- Small reversible changes
- Human approval before publishing
- No secrets in git
- Use project-local tooling and lockfiles
- Keep the repo clean and auditable
